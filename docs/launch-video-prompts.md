# Silent product launch video prompts

Open one file, copy its complete contents, and paste it into the Codex session for that project's own repository. Each prompt requests finished videos plus editable sources and reproduction instructions. No existing portfolio screenshot should be used as a high-resolution master.

- [Tracewise prompt](launch-videos/tracewise-prompt.md): 35–45 seconds; real execution → prediction → typing.
- [NINES prompt](launch-videos/nines-prompt.md): 35–45 seconds; predict → simulate → incident response.
- [CaseIntel prompt](launch-videos/caseintel-prompt.md): 45–60 seconds; inspired by the current CaseIntel landing page, following one synthetic matter through a working legal day.

All request genuine 4K60 masters when supported, native 1080p60 portfolio MP4s, full-resolution posters, no audio streams, and no commits or deployment. The CaseIntel prompt explicitly uses its navy/parchment/gold editorial identity and Newsreader/Public Sans/IBM Plex Mono typography rather than the portfolio's visual theme.
